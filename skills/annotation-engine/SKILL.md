# Skill: Annotation Engine

## Amaç
Screenshot üzerine çizim ve metin ekleme altyapısını standartlaştırmak.

## V1 araçları
- arrow
- rectangle
- text

## Kurallar
1. Her anotasyonun açık bir veri modeli olsun.
2. Undo desteği düşünülerek state tasarlansın.
3. Render mantığı export mantığından kopuk olmasın.
4. PNG export sonunda anotasyonlar doğru konumda görünmeli.
5. Gereksiz karmaşık araçlar V1'e eklenmemeli.

## Beklenen çıktı
- annotation type modeli
- state yönetimi önerisi
- render yaklaşımı
- export yaklaşımı
- test senaryoları
