# Shotline

Hızlı ve hafif masaüstü ekran görüntüsü alma ve ekran kaydı uygulaması. Electron + React + TypeScript.

## Hedefler
- hızlı screenshot alma
- alan seçme
- anotasyon
- clipboard ve dosya kaydetme
- screen recording
- ileride upload, OCR, blur ve history

## İlk kapsam
- screenshot capture
- selection overlay
- PNG save / clipboard
- temel recording akışı

## Teknoloji
- Electron
- React
- TypeScript
